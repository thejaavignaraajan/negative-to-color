How the Conversion Works

📊

Step 1 — Range Analysis

Builds a histogram for R, G, B channels. Finds the 1st and 99th percentiles — the film base and deepest shadow — to handle any base colour (orange or cyan).

🔄

Step 2 — Invert + Normalise

Each channel inverted as (max−neg)×255/(max−min). No clipping. Film base → black, scene highlights → white.

✨

Step 3 — Gamma Correction

sRGB gamma (γ=2.2) brightens midtones so the result looks natural on modern displays instead of too dark or flat.

🎨

Step 4 — Live Colour Controls

Canvas-based pixel editing applies R/G/B offsets, brightness, contrast (Photoshop formula), and saturation in real time — no server round-trip needed.
